# UX_DEBT (honest backlog)

Items below are **not** RC4-D blockers for the observe-only release candidate, but they are real follow-ups for a future UX / operator-experience phase.

**Primary backlog (called out for RC4-D1):**

1. **Full RU / EN i18n polish** — unify all panels on dictionary-driven copy; remove remaining hardcoded RU-only blocks where EN mode should win.
2. **Professional terminal UX polish** — typography rhythm, motion, focus rings, and keyboard discoverability for power users.
3. **Resize / window behavior** — edge cases for minimum sizes, collision, and multi-monitor offsets.
4. **Full visual status system** — one coherent language for ok / warning / closed / no-data across all panels (extends current badge work).

**Additional panel-level follow-ups:**

5. **Full redesign of panel 17 (Live market stream)** — density, proof/freshness hierarchy, and technical parameters layout for faster scanning under stress.
6. **Strengthen panel 00 (Core overview) as a navigation hub** — clearer block map, status legend, and focus affordances aligned with workspace tabs.

These items must remain **compatible** with observe-only safety: no trading controls, no execution, no proof bypass.
