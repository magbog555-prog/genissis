# Observable Core Machine v0.7.5

Наблюдаемая вычислительная машина ядра.

## Запуск

```powershell
npm install
npm run dev
```

## Что добавлено в v0.7.5

- исправлено скругление верхней полосы окна, особенно у свернутых блоков;
- добавлены шрифты интерфейса;
- добавлены шрифты кода и цифр;
- добавлены 5 новых тем: Dracula, Nord, Tokyo Night, Gruvbox Dark, Monokai Pro;
- добавлены настройки насыщенности, контраста и свечения;
- у каждого блока появилась кнопка `●` в заголовке: она циклически меняет цвет блока;
- в настройках Screen blocks можно выбрать цвет каждого блока точечно;
- цвета блоков сохраняются в рабочей сцене / workspace tab;
- сохранены рабочие вкладки, удаление вкладок, composer, темы, масштаб, плотность, compact, pop-out и сохранение раскладок.

## Важно

v0.7.5 сделана поверх v0.7.4 Workspace Tabs Delete. Базовая механика окон не переписывалась.


## v0.7.6

- Верхние полосы окон теперь сильнее заливаются цветом блока.
