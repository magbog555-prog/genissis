# UI Polish Hotfix v0.8.4

Изменения:
- Верхняя панель больше не выглядит круглой по умолчанию: радиус по умолчанию снижен до 2px.
- Настройка скругления теперь начинается с 0px, можно сделать полностью квадратный интерфейс.
- Скругление применяется последовательно к верхней панели, вкладкам, кнопкам, окнам и настройкам.
- Исправлены серые системные скроллбары: теперь они окрашены в тему интерфейса.
- Кнопка цвета окна стала заметнее, цветовой попап получил RU/EN подписи.
- Цвет окна можно менять через кнопку ● в заголовке окна или через настройки блоков.
- Выполнена production-сборка Vite.
