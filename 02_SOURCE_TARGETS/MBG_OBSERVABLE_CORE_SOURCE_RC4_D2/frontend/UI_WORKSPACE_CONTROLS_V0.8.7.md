# UI Workspace Controls v0.8.7

Исправления:
- Убрано самосжатие окон: минимальные размеры окон усилены, сохранение размеров не принимает слишком маленькие значения.
- Верхняя панель и вкладки подчиняются общему радиусу интерфейса.
- Вкладки остаются в две строки и прокручиваются колесиком мыши прямо по верхней панели.
- Состояние активной рабочей сцены автосохраняется: позиции, размеры, видимость, цвета, тема, радиус, шрифты.
- Шрифты применяются принудительно к кнопкам, вкладкам, заголовкам, JSON/pre/code.
- Панели DTO/JSON получили более удобную внутреннюю раскладку и заполнение высоты.
- Настройки цветов по каждой панели сохранены и усилены через блоки в настройках и кнопку цвета на заголовке окна.

Проверка:
- npm install
- npm run build
