# FRONTEND UI SETTINGS FIX REPORT

## Что исправлено
- Настройки темы теперь реально применяются через `document.body.dataset.theme`.
- Масштаб теперь пробрасывается в CSS-переменную `--ui-scale` и влияет на рабочую область.
- Скругления теперь пробрасываются в CSS-переменную `--radius` и применяются к окнам, кнопкам, настройкам.
- Плотность теперь пробрасывается в CSS-переменную `--density` и `body[data-density]`.
- Шрифты интерфейса и моноширинный шрифт теперь применяются через `body[data-ui-font]` и `body[data-mono-font]`.
- Насыщенность, контраст и свечение теперь применяются через CSS-переменные.
- Заголовки окон переведены на русский через `windowMeta`.
- Настройки темы, плотности и шрифтов получили русские названия.
- Убраны смешанные подписи вида `Blocks`.
- Исправлены русские подписи создания/копирования/импорта рабочих сцен.
- Настройки сохраняются в localStorage и применяются сразу без перезагрузки.
