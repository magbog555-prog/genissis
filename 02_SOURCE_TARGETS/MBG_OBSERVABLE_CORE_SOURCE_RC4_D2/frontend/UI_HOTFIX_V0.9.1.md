# UI Hotfix v0.9.1

- Горячие клавиши вынесены в отдельную правую колонку рядом с настройками, больше не ломают раскладку настроек.
- Расширены диапазоны настроек темы, чтобы изменения были заметны визуально.
- Усилены эффекты темы: оттенок, стекло, сетка, металл заголовков, тени, scanlines, шум и резкость текста.
- Сборка проверена через `npm run build`.
