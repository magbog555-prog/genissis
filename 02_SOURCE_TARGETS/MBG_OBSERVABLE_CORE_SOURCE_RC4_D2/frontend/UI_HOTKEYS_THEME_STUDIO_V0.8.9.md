# UI HOTKEYS + THEME STUDIO V0.8.9

Implemented:
- F1–F12 scene switching.
- Ctrl+T new scene.
- Ctrl+W close active scene.
- Ctrl+Tab / Ctrl+Shift+Tab scene navigation.
- Ctrl+S saves current scene payload.
- F-key hints on scene tabs.
- Extended theme controls:
  - accent hue
  - glass density / panel opacity
  - grid intensity
  - header metal strength
- Theme variables are centralized via CSS custom properties.
- Build verified with `npm run build`.
